# Инструкции проекта DiatomDINO

Перед началом любой работы обязательно полностью прочитай `PROJECT_CONTEXT.md`.

Работай в цикле Observe → Plan → Act → Verify.

Перед изменениями сначала собери минимально необходимый контекст. После каждого
существенного действия проверяй результат и опирайся на факты, а не на
предположения. При ошибке установи причину, выбери безопасную альтернативу и
повтори проверку.

Для изменений кода:

- делай минимально достаточные изменения;
- не затрагивай несвязанный код;
- запускай релевантные проверки;
- в финальном ответе перечисляй изменённые файлы, выполненные команды и их результаты.

Для операций с `datasetDiatom`:

- сначала валидируй все источники и планируемые идентификаторы;
- не перезаписывай и не удаляй данные без явного запроса пользователя;
- перед изменением существующих CSV создавай резервные копии;
- после записи проверяй соответствие `images`, `labels`, `metadata.csv` и `taxonomy.csv`;
- не запускай одноразовые скрипты миграции автоматически: пользователь переносит и запускает их в DataSphere.

Если задача меняет структуру проекта или формат датасета, обнови
`PROJECT_CONTEXT.md` в рамках той же задачи.
